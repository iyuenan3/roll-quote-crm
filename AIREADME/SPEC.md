# SPEC · roll-quote-crm · 对外输入契约

> 本项目无网络 API。对外契约 = 客户在微信按固定格式填写、商家粘贴进系统的「下单文本」格式，及其解析与计价规则。

## 下单文本格式（客户填）
首行可选：`客户：<客户名>`（不写则在 UI 先选客户）。
其后每行一个规格：`<品名> <尺寸> <数量>`，空格分隔。

示例：

```
客户：张三
05纯低温胶 2500*893 21张
05纯低温胶 2500*893 25张
06纯低温胶 420*50000 22卷
```

## 字段规则
- 品名：与系统 products.name 匹配（精确 → 别名 → 模糊）。匹配不到则该行标红，商家手选或先建产品。
- 尺寸：`宽*长`，单位毫米。分隔符接受 `*` / `×` / `x` / `X`，全 / 半角皆可。原文保留为 raw_spec 显示于「规格」列。面积乘法可交换，宽长顺序不影响计价。
- 数量：`<数字><单位>`，单位 = 张 或 卷（接受中间空格，如 `21 张`）。

## 计价公式（不可变契约）

```
area_sqm   = (width_mm/1000) × (height_mm/1000)
unit_price = round(roll_price × area_sqm ÷ 21, 3)        // 精确到小数点后 3 位（D6）
amount     = round(roll_price × area_sqm ÷ 21 × qty, 0)  // 四舍五入到整数元（D6），用未截断单价乘
```

- roll_price = 取价顺序：该「客户 × 产品」当前专属报价（quotes）→ 无则回落该产品当前基础价（product_prices）→ 都无则不计价、拦下单。每卷价，卷 = 21㎡。客户价永远优先，基础价只回落（见 DECISIONS D7）。
- 张 / 卷同一公式：整卷面积 ≈ 21㎡，单价自然退化为每卷报价。
- 手动覆盖行（is_manual=1）跳过公式，直接取商家手填单价 / 金额。
