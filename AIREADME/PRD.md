# PRD · roll-quote-crm

## 目标
让卖卷材（低温胶等）的商家，从「客户微信发尺寸 → 人工查报价 → 手算单价 → 填送货单」的易错慢链路，升级到「粘贴即出单」，并能看每客户每月消费。

## 用户
单一卷材销售商家，非技术用户。卖各种低温胶等按卷计价产品，同型号对不同客户报价不同。

## 用户问题
- 同型号客户报价各异，每单单价要现查现算，易错。
- 客户按「长 × 宽 × 张数」裁切下单，单张单价要按面积占一卷（21㎡）的比例折算，手算烦。
- 看不到每个客户每月买了多少。

## 核心流程
1. 维护客户 + 产品 + 每卷报价（手录 + 边用边录）。
2. 客户微信按固定模板发单，商家粘贴，自动解析 + 按最新报价算价。
3. 价格默认沿用上次报价，本次改价可选「存为新报价」或仅一次性。
4. 生成订单 + 打印送货单（空白纸整张 / 存 PDF）。
5. 看客户 / 产品 × 月消费统计。

## 成功指标
- 一张多行订单从粘贴到出送货单 < 1 分钟，单价金额零手算。
- 商家持续录入报价、长期使用（不因初始录入门槛弃用）。

## UX 哲学
- 粘贴优先：核心入口是「贴一段文本」，不是逐字段填表。
- 算得对 > 花哨：计价正确、合计大写无误是第一位。
- 非技术友好：双击启动、按钮直白、出错有提示能手改。
