# CORE · roll-quote-crm

## 身份
卷材（低温胶等按卷 / 按㎡ 计价产品）销售的本地桌面 CRM。面向单一卷材销售商家自用：维护「客户 × 产品 × 每卷报价」，把客户微信发来的固定格式订单文本粘贴进来，自动按该客户该产品最新报价算出每行单价金额，生成订单、打印送货单、看月度消费统计。

## 使命
把「查客户报价 + 手算单张单价 + 填送货单」这条易错耗时的人工链路自动化，并让商家看得到每个客户每月买了多少。

## Non-Goals（不做）
- 不做多租户 / 多商家 SaaS：单机单用户，数据全本地。
- 不做在线部署 / 账号登录 / 云同步。
- 不做进销存 / 库存 / 财务记账：只管报价、订单、送货单、消费统计。
- 不做针式预印三联单坐标对齐：打印走空白纸整张（见 DECISIONS D2）。
- 不做客户自助下单端：客户只在微信按模板填文本，商家粘贴。

## 绝不（硬约束红线）
- 计价口径不可变：单张单价 = 该客户该产品每卷报价 × (长×宽面积 ÷ 21)，金额 = 单价 × 张数。一卷恒等于 21㎡。
- 报价是「客户 × 产品」二维，绝不退化成「产品」一维全局价。
- 报价历史只追加：改价写新 quotes 记录、旧的置 is_current=0，绝不原地覆盖丢历史。
- 订单保存时快照下单报价（roll_price_used），历史订单绝不随后续报价变动。
- 计价 / 解析核心是纯函数 + 单测，绝不把业务算法埋进 UI 组件。
- 中文产出绝不使用破折号。
